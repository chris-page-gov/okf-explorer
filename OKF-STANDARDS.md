# OKF standards and bundle discovery

Use the [central OKF standards register](https://github.com/chris-page-gov/okf-explorer/blob/main/docs/okf-standards.md) for current and historical core specifications, separately versioned semantic profiles and the public catalogue of bundles under `chris-page-gov`.

The current upstream project is [open-knowledge-format/open-knowledge-format](https://github.com/open-knowledge-format/open-knowledge-format). Google Cloud announced OKF 0.3 on [18 November 2026](https://cloud.google.com/blog/products/data-analytics/introducing-okf-v0-3).

The [machine-readable register](https://raw.githubusercontent.com/chris-page-gov/okf-explorer/main/registry/okf-standards.json) supplies version-specific pins. Select the version actually implemented by this repository and retain the source snapshot, rights and validation evidence when rebuilding. A reference update does not establish adoption of a newer core or semantic profile.

The central register links to the reviewed public bundle access directory and the dated public owner catalogue. Authenticated inventories of restricted repositories remain private.

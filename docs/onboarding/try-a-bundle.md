# Try a bundle with AI

Aim for one sourced answer and one understood limit. This is a short first
experience, not a test of every AI host. Choose an existing public example or
use the fictional attachment route below. Do not supply personal circumstances.

### Try it with your AI

Use this prompt if your AI can access the page's tools:

```text
Use this page's available tools to find the reviewed Tax-Free Childcare
record and present its evidence on the page. Identify the recorded official
source, when it was observed, and what the evidence cannot establish.
Use only returned evidence and cite the record and source. If these tools
are unavailable, say so and ask for the displayed evidence extract.
Do not decide anyone's eligibility.
```

This is a worked prompt to try, not a claim that every host has passed it.
For a human route, choose **Technical review**, search for **Tax-Free Childcare**,
then choose **Show evidence for this result** on the reviewed result. Copy the
selected evidence to an AI that accepts pasted text, preserving its source,
date and limitations. The [access guide](../ai-okf-usage.md) explains alternatives.

## Check the result

| Check | Expected evidence |
| --- | --- |
| Identity | The reviewed Tax-Free Childcare record, not a similarly named childcare scheme |
| Source | The recorded official GOV.UK source, distinguished from the prototype's own description |
| Freshness | The captured observation on 15 July 2026; no assertion that this is today's guidance |
| Limit | Saved metadata does not decide current eligibility or scheme rules |
| Unsupported follow-up | “Does this prove a particular family qualifies today?” must remain unsupported |

Ask your AI which statements came from the evidence and which were its own
interpretation. The page cannot inspect the AI's final wording. Open the
recorded official source if you need current guidance.

On 6 September 2026, a human browser journey verified the selected record,
search, evidence display and deep-link restoration. The page reported six
registered tools. No AI host invocation was performed for that check. The
candidate's [dated host observations](https://github.com/chris-page-gov/govuk-webmcp/blob/32f3d55bf34c4056a4b51b8fa00ad3c94a799d03/PROJECT_STATUS.md)
record separate results; registration, a human action and a model call are
three different kinds of evidence.

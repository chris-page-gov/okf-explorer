# Start with knowledge you can inspect

An Open Knowledge Format (OKF) bundle keeps notes, records, sources and
relationships together. Explorer helps you inspect that material. Your chosen
AI can use the evidence it can actually access; the bundle does not train a
model or guarantee its answer.

Start with a useful question. Learn the machinery when you need it.

## A useful first session

1. Open an existing example and identify its subject and limits.
2. Give a capable AI a small, labelled set of evidence and ask one question.
3. Open the cited record and check the answer against it.
4. Ask something the evidence cannot answer. A clear “not recorded” is useful.
5. Change one source note in the fictional starter and repeat the question.

The first exercise has a five-minute target, not a measured completion promise.
It has a human fallback when your AI cannot use links, files or page tools.
No account, paid model call or coding environment is needed to inspect the
examples in Explorer. Your chosen AI host may have its own access and charges.

# Warwickshire ageing population 2008 trial

The publisher describes the percentage of the population of retirement age as females aged 60+ and males aged 65+, by Super Output Area. The reference period is 2008. This is historical information.

The local projection retains all 333 observations and every area code. It renames the headers, removes numeric grouping commas and percentage signs, and adds the catalogue reference year. Other text, including trailing spaces in locality names, stays as supplied.

The offline Analytical Data 1.0.0-rc.1 check passed. Rights remain unverified because the WCC dataset page links CC BY-SA 2.0 UK and the NDL record declares UK OGL. Boundary edition, official code membership and comparisons with modern indicators need separate evidence.

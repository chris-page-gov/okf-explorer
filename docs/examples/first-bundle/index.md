# Fictional study club

An OKF 0.3 Markdown teaching collection. Six invented records demonstrate
source-linked questions, explicit reference links and missing information.
No real events, people, addresses or services are described. No human verification
is claimed. A generated Explorer projection is supplied separately.

## Build and learn

Follow [this collection's visual worked question](walkthrough.html), inspect its
[machine-readable source trails](walkthrough-data.json), or read the
[current and historical standards register](https://github.com/chris-page-gov/okf-explorer/blob/main/docs/okf-standards.md).

Use [the first-bundle guide in the Explorer repository](https://github.com/chris-page-gov/okf-explorer/blob/main/docs/onboarding/first-bundle.md). Authored inputs
are this index, the six records, questions.json, walkthrough.case.json and
LICENSE.md. JSON, AI context, walkthrough, checksums and ZIP are generated by
scripts/build_learning_example.py.
Local Markdown links are references, not inferred domain predicates.

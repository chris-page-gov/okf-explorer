# Fictional study club

An OKF 0.2 Markdown teaching collection. Six invented records demonstrate
source-linked questions, explicit reference links and missing information.
No real events, people, addresses or services are described. No human verification
is claimed. A generated Explorer projection is supplied separately.

## Build and learn

Use [the first-bundle guide in the Explorer repository](https://github.com/chris-page-gov/okf-explorer/blob/main/docs/onboarding/first-bundle.md). Authored inputs
are this index, the six records, questions.json and LICENSE.md. JSON, AI context,
checksums and ZIP are generated by scripts/build_learning_example.py.
Local Markdown links are references, not inferred domain predicates.

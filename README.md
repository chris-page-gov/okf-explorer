# OKF Explorer

Use knowledge you can inspect with your AI. Open Knowledge Format (OKF) keeps
source-linked notes, records and relationships in a reusable bundle. Explorer
helps you browse that material and check what supports an answer.

## Start here

[Try an existing bundle with AI](docs/onboarding/try-a-bundle.md), then inspect
its evidence and limits. You can use a human browser route if your AI cannot
access page tools, links or files. Explorer does not itself run an AI model.

The catalogue includes the experimental **govuk-webmcp** application as a
submitted, frozen competition candidate. Its introduction lives here; no
changes to that candidate are required. [Watch Chris Page’s AI and WebMCP
demonstration](https://www.youtube.com/watch?v=mPk-vv1LfIU), then follow the
[first exercise](docs/onboarding/try-a-bundle.md#watch-the-webmcp-demonstration).
Bundle status, source review and AI host compatibility are different things.

## Documentation

The [documentation map](docs/index.md) separates getting started, task guides,
the optional [project studio](docs/project-studio/index.md),
[beginner reference](docs/beginners/index.md), technical contracts and historical
reviews. You can finish with a sourced answer or a private bundle; building an
app and publishing are optional later steps.

## Contribute

Use the [development guide](docs/development.md) for locked setup, local builds,
testing and the governed publication process. The [repository guide](docs/repository-guide.md)
explains authored/generated boundaries. Preserve source authority, derivation,
rights, freshness and lifecycle; a passing build does not establish truth.

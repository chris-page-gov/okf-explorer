# Delivery and citation diagnosis

The saved report is accessible as a Library research artefact. The original supplementary
ZIP and linked files were not present in the current runtime or returned as separate files
in the earlier Library listing. That is not proof they never existed, were deleted, or can
never be recovered. The private export/runtime internals and original execution traces are
not available for a conclusive causal diagnosis.

The user's examples contain escaped Markdown and bold markers interrupting links. The
saved final-report text has ordinary Markdown attachment links. This locates a difference
between the saved text and the displayed/copied text, but does not identify which renderer,
copy operation or exporter introduced it. Formatting and absent attachment bytes are two
separate problems. Fixing one cannot establish the other.

The assertion table is not a machine-verifiable execution receipt. Its original claimed
checksums, schema validation and ZIP scan cannot be independently reproduced without the
missing artefacts. No claim is made here that all earlier statements were false: they are
unverified. The acceptance status is corrected accordingly.

The replacement source/input hashes are measured from actual available bytes. Source
associations restored from citation metadata are not automatically validated claims.
The new test receipt reports only runs actually performed on reconstructed code and fixtures.
The proposed export root cause remains a hypothesis, not a verified defect in a named product.
